# For Sharu

Open `index.html` to start. On GitHub Pages, keep every folder exactly as it is.

- `index.html` - page structure and all the text on the landing and home screens
- `css/style.css` - colors, fonts, layout, animations
- `js/config.js` - the 3-digit code (`PASSCODE`) and the lists of photos and images
- `js/app.js` - landing, code screen, lily bloom, home page, back button
- `js/reminder.js` - the "Sharannya's Short MV" button (loader, film collage, song)
- `which.html` - the "Which one is it Sharu?" page
- `assets/photos` - her 12 photos for the film collage (swap a file, keep its name)
- `assets/audio/alfaaz.mp3` - the song
- `assets/images`, `assets/lilies`, `assets/gallery` - backgrounds and lily pictures

Keep your `CNAME` file in the repository root if you use a custom address.
